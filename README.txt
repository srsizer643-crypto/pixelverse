PixelVerse - طريقة الرفع على GitHub من الموبايل
================================================
1) افتح مستودع الموقع (srsizer643-crypto.github.io) > Add file > Upload files.
2) ارفع index.html + فولدرات assets و pages و data بنفس الأسامي.
   (لو الموبايل مش بيرفع فولدرات: Add file > Create new file واكتب في الاسم مثلا: pages/game.html)
3) Commit changes وانتظر دقيقة.

لتحديث الموقع بعد كده عدّل ملف data/site.js بس:
- لعبة جديدة: انسخ كتلة اللعبة وحطها اول قائمة games (غيّر id و name و desc و cover و embed).
- التطوير الاسبوعي: عدّل كتلة weekly.
- الاحصائيات: اكتب اسم حسابك في stats.goatcounter.

اللعبة الاصلية (g3an_3tshan) ما اتغيرش فيها اي حاجة. التشغيل جوّه الموقع بيحمّلها بـ iframe من رابطها الاصلي.
